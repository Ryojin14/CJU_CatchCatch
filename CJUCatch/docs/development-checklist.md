# 개발 체크리스트

이 파일을 CJUCatch의 "다음에 무엇을 할지"를 확인하는 기준 문서로 사용합니다.

## 기본 원칙

- [x] CJUCatch를 기존 참고 프로젝트와 분리해서 유지하기
- [x] 새 코드와 새 아트만 사용하기
- [x] 클라이언트 빌드에 안내문, 개인정보, 경고 텍스트 파일 포함하기
- [x] 클라이언트 에러 로그 파일 남기기
- [ ] 운영 환경의 모든 통신을 HTTPS와 WSS로만 유지하기
- [x] 서버에 요청 횟수 제한과 페이로드 크기 검증 추가하기

## 1단계: 기초 구성

- [x] 클라이언트, 서버, 공유 프로젝트를 분리해서 만들기
- [x] `Instance`, `Public`, `Private` 개념 정의하기
- [x] 최소한의 SignalR 실시간 허브 추가하기
- [x] 비공개 인스턴스용 비밀번호 해시 처리 추가하기
- [x] 클라이언트 첫 화면 초안 만들기
- [x] 우클릭으로 조작할 수 있는 떠 있는 캐릭터 창 추가하기

## 2단계: 기본 사용 흐름

- [x] 표시 이름 입력 추가하기
- [x] 서버 주소 입력 추가하기
- [x] 인스턴스 생성 폼 추가하기
- [x] 인스턴스 참가 폼 추가하기
- [x] 공개 인스턴스 새로고침 목록 추가하기
- [x] 생성/참가 동작을 서버와 연결하기
- [x] 참가한 사용자 목록을 클라이언트에서 실시간으로 보여주기
- [x] 인스턴스 나가기 흐름 추가하기

## 3단계: 캐릭터와 오버레이

- [x] 떠 있는 캐릭터 우클릭 조작 지원하기
- [ ] 임시 도형 캐릭터를 오리지널 임시 아트로 교체하기
- [x] 같은 인스턴스의 다른 참가자를 화면 위에 표시하기
- [x] 단순 위치와 상태를 동기화하기
- [x] 캐릭터 클릭 기반 말풍선 입력과 표시 추가하기
- [ ] 로컬 캐릭터 드래그 지원 보강하기
- [x] 입력 반응 기반 콤보 표시 추가하기
- [x] 입력 반응 기반 파티클 효과 추가하기
- [x] 키보드/마우스 활동 감지 정책 확정하기

## 4단계: 보안 강화

- [x] ~비밀번호 해시를 Argon2id 또는 더 강한 메모리 하드 방식으로 변경하기~ (지인용이므로 현재 수준 유지)
- [x] 인스턴스 생성/참가 시도 제한 추가하기
- [x] 이름, 인스턴스 이름, 메시지 길이를 클라이언트와 서버 양쪽에서 제한하기
- [x] 서버 로그를 개인정보를 남기지 않는 운영 로그 수준으로 줄이기
- [x] 지인 테스트 전에 간단한 보안 점검 체크리스트 추가하기

## 5단계: 지인 테스트

- [ ] 저비용 호스팅에 서버 배포하기
- [ ] 서버용 커스텀 도메인 설정하기
- [ ] 클라이언트의 로컬 개발 서버 주소를 실제 서버 주소로 교체하기
- [ ] 두 명 이상으로 실제 테스트 진행하기
- [ ] 최소한의 공유 데이터만 보이는지 확인하기
