# 보안 점검 체크리스트

지인 테스트를 시작하기 전에 아래 항목을 빠르게 다시 확인합니다.

## 1. 통신

- [ ] 운영 서버 주소가 `https://`로 시작하는지 확인
- [ ] 클라이언트 허브 주소가 `wss://`로 연결되는지 확인
- [ ] 개발용 `localhost` 주소가 배포 빌드에 남아 있지 않은지 확인

## 2. 서버

- [ ] 공개 포트가 필요한 것만 열려 있는지 확인
- [ ] 인스턴스 생성/참가 시도 제한이 켜져 있는지 확인
- [ ] SignalR 최대 메시지 크기 제한이 유지되는지 확인
- [ ] 서버 로그가 `Warning` 이상으로 설정되어 있는지 확인
- [ ] 비공개 인스턴스 비밀번호가 평문으로 저장되지 않는지 확인

## 3. 클라이언트

- [ ] 표시 이름, 인스턴스 이름, 비밀번호 길이 제한이 유지되는지 확인
- [ ] 입력 감지가 활동 여부만 처리하고, 입력 내용 자체는 저장하지 않는지 확인
- [ ] 에러 로그에 비밀번호나 민감한 값이 남지 않는지 확인
- [ ] 안내문 텍스트 파일(`NOTICE.txt`, `PRIVACY.txt`, `WARNING.txt`)이 빌드 결과물에 포함되는지 확인

## 4. 테스트

- [ ] 서로 다른 두 클라이언트로 같은 인스턴스 접속 테스트 완료
- [ ] 비공개 인스턴스에 비밀번호 없이 들어가지지 않는지 확인
- [ ] 잘못된 인스턴스 코드와 비밀번호를 여러 번 넣었을 때 제한이 걸리는지 확인
- [ ] 서버를 껐다 켰을 때 임시 메모리 데이터가 초기화되는지 확인

## 5. 배포 직전

- [ ] 디버그용 메모, 샘플 주소, 임시 테스트 코드 제거
- [ ] 배포용 빌드가 정상 실행되는지 확인
- [ ] 지인들에게 전달할 사용법과 주의사항 파일 최종 확인
